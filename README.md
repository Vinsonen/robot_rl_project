# 两轮机器人强化学习项目

这是一个使用深度强化学习（DQN）训练两轮自平衡机器人的项目。通过本项目，你将学习如何设计强化学习环境、实现DQN算法，以及训练机器人保持平衡。

## 项目结构

```
simple_robot_rl/
├── robot_env.py     # 机器人环境定义
├── dqn_agent.py     # DQN智能体实现
├── train_agent.py   # 训练脚本
├── test_agent.py    # 测试脚本
└── README.md        # 项目说明
```

## 安装依赖

本项目需要以下Python库：
- numpy
- tensorflow
- matplotlib

可以使用pip安装这些依赖：

```bash
pip install numpy tensorflow matplotlib
```

## 项目组件说明

### 1. 机器人环境 (robot_env.py)

`TwoWheelRobotEnv`类定义了一个简化的两轮机器人物理模型和交互环境。主要功能包括：

- **状态空间**：[角度, 角速度, 位置, 速度]
- **动作空间**：连续的力输入 [-1.0, 1.0]
- **奖励函数**：综合考虑平衡、位置和速度
- **物理模拟**：简化的动力学模型
- **渲染功能**：使用matplotlib可视化机器人状态

### 2. DQN智能体 (dqn_agent.py)

`DQNAgent`类实现了深度Q网络算法，主要特点包括：

- **神经网络结构**：2个隐藏层，每层24个神经元
- **经验回放**：使用回放缓冲区存储和采样经验
- **目标网络**：定期更新的目标网络以提高稳定性
- **ε-贪婪策略**：平衡探索和利用

### 3. 训练脚本 (train_agent.py)

训练脚本提供了完整的训练流程：

- **参数设置**：回合数、批量大小、渲染频率等
- **训练循环**：执行多个回合的训练
- **模型保存**：定期保存训练好的模型
- **历史记录**：记录和可视化训练进度

### 4. 测试脚本 (test_agent.py)

测试脚本用于评估训练好的模型：

- **模型加载**：加载保存的模型权重
- **性能评估**：在多个回合中测试模型性能
- **动画生成**：创建机器人运行的GIF动画

## 快速开始

### 1. 训练智能体

```bash
python train_agent.py
```

训练参数可以在脚本中修改：
- `episodes`：训练回合数
- `batch_size`：批量大小
- `render_every`：渲染频率

### 2. 测试智能体

```bash
python test_agent.py
```

确保修改脚本中的`model_path`指向你训练好的模型文件。

## 学习步骤

按照以下步骤逐步学习本项目：

1. **理解环境**：阅读`robot_env.py`，了解状态空间、动作空间和奖励函数的设计
2. **理解算法**：阅读`dqn_agent.py`，学习DQN算法的实现细节
3. **运行训练**：执行`train_agent.py`，观察训练过程
4. **分析结果**：查看训练历史图表，理解学习曲线
5. **测试模型**：执行`test_agent.py`，评估训练效果
6. **修改参数**：尝试调整超参数，观察对训练的影响

## 扩展思路

## 常见问题

### 1. 训练不收敛怎么办？

- 检查奖励函数设计
- 调整学习率和批量大小
- 增加训练回合数
- 检查物理模型是否合理

### 2. 如何提高训练效率？

- 使用GPU加速训练
- 增加批量大小
- 调整探索率衰减策略

### 3. 如何评估模型性能？

- 在多个初始条件下测试
- 计算平均奖励和稳定性指标
- 观察机器人的平衡能力和位置控制
